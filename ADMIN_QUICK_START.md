## 🎯 Most Common Tasks

### Change Game Title
1. Go to **Content Editor** tab
2. Edit "Game Title" field
3. Click **💾 Save Content Changes**
4. Refresh game to see changes

### Change Colors
1. Go to **Visual Theme** tab
2. Click color pickers to choose colors
3. Watch **Live Preview** update
4. Click **💾 Save Theme**

### Add Story Milestone
1. Go to **Storyline** tab
2. Click **➕ Add New Milestone**
3. Enter level number (e.g., 7)
4. Enter milestone message
5. Click **💾 Save Storyline**

### Gift Player Items
1. Go to **Players** tab
2. Find player in table
3. Click **🎁 Gift** button
4. Choose gift type (Gold/XP/Equipment)
5. Enter amount or select item
6. Click **🎁 Send Gift**

### Change Background
1. Go to **Visual Theme** tab
2. Select "Background Style": Image
3. Paste image URL
4. Check preview
5. Click **💾 Save Theme**

---

## 📦 Backup & Restore

### Backup Current Settings
1. Click **📥 Export Settings** (Overview tab)
2. Save `spartan-game-settings.json`
3. Store safely

### Restore Settings
1. Click **📤 Import Settings**
2. Select saved `.json` file
3. All settings update automatically

## 🐛 Quick Fixes

### "Can't login"
→ Check username/password in `admin-enhanced.js` line 6-9

### "Changes not showing"
→ Click "Save All Changes" then refresh game (Ctrl+F5)

### "Players not loading"
→ Need at least one registered player in game

### "Colors look wrong"
→ Use valid hex codes (#RRGGBB format)

## 🔥 Pro Tips

1. **Always export before major changes** - Safety first!
2. **Test in preview** - See changes before applying
3. **One change at a time** - Easier to identify issues
4. **Keep themes consistent** - Match colors across sections
5. **Use emoji sparingly** - Too many can be distracting
6. **Save often** - Each tab saves independently
